# E-commerce Sales Analysis

## Project Overview
This project analyzes an e-commerce retail dataset using MySQL and Microsoft Excel to identify sales trends, customer activity, country performance, and top-selling products.

## Tools Used
- **MySQL:** Data analysis using SQL queries and aggregate functions.
- **Microsoft Excel:** Data analysis, PivotTables, charts, and dashboard creation.

## Key Performance Indicators (KPIs)
- **Positive Sales Revenue:** 10,666,684.54
- **Net Line Value:** 9,747,747.93
- **Total Orders:** 19,960
- **Unique Customers:** 4,338
- **Average Order Value:** 534.40

*Note: Positive sales revenue excludes rows with non-positive quantities or unit prices. Net line value includes negative quantities, which may represent returns or cancellations.*

## Key Findings
1. **Sales by Country:** The United Kingdom generated the highest positive sales revenue, approximately 9.03 million.
2. **Monthly Performance:** November 2011 was the highest-revenue month, with approximately 1.51 million in positive sales revenue.
3. **Top Products:** Regency Cake Stand 3 Tier and Paper Craft, Little Birdie were among the highest-revenue products.
4. **Returns and Cancellations:** The dataset contains negative-quantity transactions, which affect net sales values.
5. **Customer Activity:** The analysis identified 4,338 unique customers with qualifying sales.

## Project Files
- `E Commerce Sales Analysis Dashboard.xlsb` — Excel workbook containing the dashboard, KPIs, PivotTables, and charts.
- `Ecommerce_sales_Analysis.sql` — SQL queries used for the analysis.

## Conclusion
This project demonstrates practical skills in SQL data analysis, Excel reporting, KPI calculation, and dashboard development. The results help explain sales performance across time, countries, and products.
